
Kodda hangi ara koşulun karşılığı var, hangisinin yok, aşağıda çıkardım. Taktik içerik isteyen koşullarda (atış zamanı, savunma tipi, kaçış eşiği) nasıl hesaplanacağını ben önermiyorum. Onlar için yalnızca kodda hazır duran değerleri listeledim. Bu değerleri nasıl birleştireceğine sen karar vereceksin.

Yapısal bir not

conditions.hpp dosyasındaki yorumda koşulların "saf sorgu" olarak tutulduğu yazıyor: karar yapısı değişse de koşullar aynı kalıyor. Yeni FSM'in ara koşullarını da aynı yere birer isimli fonksiyon olarak eklersen (can_fire, should_hot_defend gibi), FSM dosyası sadece if(condition::x) goto->Y satırlarından oluşur. İçlerini sonradan doldurabilirsin. Bu tamamen senin kararın. FSM dosyalarına ben dokunmuyorum, conditions'a da sen söylemeden eklemem

her tick:
    üst_kurallar()
    state()


üst_kurallar():
    if(enemy_range <= MAR)
        goto->Out
    if(füze_range + hız <= kritik_mesafe)
        goto->Out


Commit:   // atış kararı
    yaklaş(pursuit | flank/crank)   // nasıl yaklaşacağım?

    if(füze bitti)
        goto->Abort

    atabilir_miyim =
        atacak füzem var
        && hedef WEZ'de
        && pitbull olana kadar destek verebilirim
        && |ATA| <= atış limiti

    nerede_atmalıyım()   // !!!!! düşmanın hot-cold-flank-beam olması da önemli

    if(atabilir_miyim && at)
        fire
        goto->Support

    if(düşman benden önce ateş etti)
        goto->Trade

    if(düşman cold)
        goto->Chase


Support:   // atış sonrası destek
    if(!(pitbull || lost))
        crank()

    if(düşman ateş etti)
        goto->Trade

    if(pitbull || lost)
        goto->Reasses


Support_w_Threat:   // atış sonrası havada düşman füzesi varken destek
    if(!üst kurallar sağlandı)
        support devam
        if(pitbull || lost)
            goto->Reasses
    else
        goto->Defend


Trade:   // karşılıklı vuruşma hesapları
    if(havada füzem var)
        if(pitbull)
            goto->Defend

        füze_değerlendirmesi()   // atmalı mıyım + nerede atmalıyım

        if(düşman füzesi pitbull olmadan füzemi pitbull'a sokarım)
            goto->Support_w_Threat
        if(düşman füzesi pitbull olduktan sonra ama vurulmadan önce sokarım)   // out'u da hesaba katar
            goto->Support_w_Threat
        if(pitbull'a sokamadan kaçmam gerekir)
            goto->Defend

    else
        trade_hesapla()   // atmalı mıyım, savunmalı mıyım?

        if(şimdi atmalıyım)
            fire
            goto->Trade

        if(x sn/nm sonra atmalıyım)
            yaklaş(a° ATA)   // derece yerine flank mı pursuit mi de olabilir?
            mesafe/süre bekle
            if(süre geldi)
                fire
                goto->Support_w_Threat

        if(savunmalıyım)
            goto->Defend


Defend:   // karşıdan füze geliyorsa nasıl ve ne zaman savunacağına karar verir
          // füze atmak istiyorsa uçağı hot'ta veya flank'te tutarak savunmaya çalışır
    atmak_istiyorum = düşmana füze atmak istiyor muyum?   // evet ise mümkünse out yapmadan yaklaşmaya çalışır

    if(hot defend)   // closure'u düşürürsem füze yetişemez mi?
        crank()
        if(istediğim koşul sağlandı)
            fire
            goto->Support_w_Threat

    if(cold defend)
        goto->Out

    if(füze tehlikesiz)
        goto->Reasses


Out:   // çıkış manevrası state'i
    out()

    if(out tamamlandı)
        if(tehdit var)
            goto->Defend
        else
            goto->Reasses


Chase:   // düşman cold ise nasıl kovalayacağını, menzile giriyorsa ne zaman füze atacağını belirler


Recommit:   // skate veya out sonrası nasıl ve ne zaman recommit edeceğine karar verir


Reasses:   // state amacına ulaştıysa buraya gelinir, sonraki adımda ne yapacağına karar verir
           // ör: Support'ta füze pitbull'a girdiyse


Abort:
    abort()
