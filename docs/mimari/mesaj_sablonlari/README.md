# Mesaj örnekleri

Çalışan Python–C++ bağlantısının mesajları [tcp](tcp/README.md) klasöründedir. Bir dış adım için bütün uçakların ölçümleri tek `state`, bütün uçuş komutları ve atışlar tek `command` mesajında taşınır.

Alanların anlamı ve birimler [veri referansında](../../veri_info/SIMULASYON_VERI_REFERANSI.md) tanımlanır. Bu klasörün JSON dosyaları çalışma zamanında program tarafından okunmaz; sözleşmenin somut örnekleridir.
